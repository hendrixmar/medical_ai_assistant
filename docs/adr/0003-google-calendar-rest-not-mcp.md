# Call the Google Calendar API directly, not through an MCP server

The original spec required a "Google Workspace MCP" integration. Under ADR 0002 the backend, not the model, performs calendar operations, so an MCP server's main benefit (exposing tools to a model) does not apply. No server evaluated in October 2026 met the requirements: Google's hosted Calendar MCP is in Developer Preview and has no client-supplied event id or Meet creation status; the community servers either lack a client-supplied id or are built for a single operator's own accounts. The REST API gives idempotent creation through a client-supplied event `id` (a retry gets 409), the asynchronous Meet `conferenceData.createRequest.status`, and the join URL in `conferenceData.entryPoints`, using three scopes: `calendar.events.owned`, `calendar.freebusy` and `calendar.calendarlist.readonly`.
